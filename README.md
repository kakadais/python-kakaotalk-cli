# 미니 카카오톡 CLI

Python 기초 문법으로 배우는 로컬 1:1 텍스트 채팅 예제입니다.
실제 카카오톡 서비스와 연결되는 프로그램은 아닙니다.

한 컴퓨터에서 서버 1개와 클라이언트 2개를 실행합니다.
닉네임을 정하고 메시지를 주고받을 수 있으며, `/종료`로 대화를 끝냅니다.
회원가입, 친구 목록, 대화 저장은 없습니다.

## 준비

- Python 3가 필요합니다.
- 추가 패키지 설치는 필요 없습니다.
- 터미널을 3개 열고, 모두 이 프로젝트 폴더로 이동합니다.
- macOS와 Linux에서는 `python3`, Windows에서는 환경에 따라 `python`을 사용합니다.

## 실행

터미널 1에서 서버를 실행합니다.

```sh
python3 server/main.py
```

터미널 2에서 첫 번째 클라이언트를 실행하고 닉네임을 입력합니다.

```sh
python3 client/main.py
```

터미널 3에서도 같은 명령으로 두 번째 클라이언트를 실행합니다.

```sh
python3 client/main.py
```

두 화면에 `1:1 대화를 시작합니다`가 나오면 메시지를 입력하고 Enter를 누릅니다.
첫 사람이 기다리는 동안 입력한 메시지는 두 번째 사람이 접속한 뒤 전달됩니다.

예를 들어 터미널 2에서 닉네임을 `민수`로 정하고 `안녕!`을 입력하면,
터미널 3에 `민수: 안녕!`이 나타납니다. 반대 방향으로도 보낼 수 있습니다.

어느 한쪽에서 `/종료`를 입력하면 두 클라이언트와 서버가 종료됩니다.
상대가 나가면 입력 중이더라도 추가로 Enter를 누를 필요 없이 종료됩니다.
다시 대화하려면 서버와 두 클라이언트를 다시 실행합니다.
서버는 두 사람이 연결된 뒤 새 접속을 받지 않습니다.

서버를 중지할 때는 서버 터미널에서 Ctrl+C를 누릅니다.

## 파일 구성

```text
kakaotalk-cli/
├── server/
│   ├── main.py      # 서버 실행 순서
│   └── module.py    # 접속 대기, 메시지 전달, 연결 종료
├── client/
│   ├── main.py      # 닉네임, 반복문, 메시지 만들기
│   └── module.py    # 서버 접속, 동시 입력·수신, 연결 종료
├── tests/
│   └── test_chat.py # 실제 프로그램을 실행하는 통신 검사 (수업에서는 생략 가능)
└── README.md
```

두 폴더의 `module.py`는 서로 다른 파일입니다.
`python3 client/main.py`로 실행하면 같은 폴더의 `client/module.py`를 가져옵니다.
서버도 같은 방식으로 실행합니다.

## main.py를 설명하는 순서

처음에는 `module.py`를 이미 만들어진 도구 상자로 생각하면 됩니다.
`main.py`에는 클래스, 스레드, 소켓 코드가 없습니다.

클라이언트부터 다음 순서로 읽어 봅니다.

1. `from module import ...`로 필요한 함수를 가져옵니다.
2. `host`, `port` 변수에 접속할 주소와 번호를 넣습니다.
3. `print()`로 안내하고 `input()`으로 닉네임을 받습니다.
4. `if`로 닉네임이 비었는지 확인하고, 비었으면 `익명`으로 정합니다.
5. `connect_server()`로 접속합니다. `None`이면 접속에 실패한 것입니다.
6. `start_chat()`으로 입력과 수신을 준비하고 `while True`로 반복합니다.
7. `read_message()`로 입력을 받고, `/종료`이면 `break`로 반복을 끝냅니다.
8. 빈 메시지가 아니면 `+`로 닉네임과 내용을 이어 붙입니다.
9. `send_message()`로 전송하고, 전송 결과를 `send_result` 변수에 저장합니다.
   성공하면 `True`, 실패하면 `False`가 돌아옵니다.
   `if send_result == False:`로 전송 실패를 확인하면 `break`로 반복을 끝냅니다.
10. `disconnect()`로 연결을 닫고 종료를 알립니다.

`if connection is not None:`은 “접속에 성공했으면 다음 코드를 실행한다”는 뜻입니다.
`message != ""`는 “입력한 내용이 빈 문자열이 아니다”라는 뜻입니다.
`text = nickname + ": " + message`는 닉네임과 내용을 붙여서 보낼 문장을 만듭니다.
예를 들어 닉네임이 `민수`, 내용이 `안녕!`이면 `민수: 안녕!`이 됩니다.

메시지 전송과 전송 결과 확인은 두 단계로 나눴습니다.

```python
send_result = send_message(connection, text)
if send_result == False:
    break
```

첫 줄은 실제로 메시지를 보내고 결과를 저장합니다.
그다음 `if`는 저장된 결과가 `False`인지 확인합니다.
실패한 경우의 `break`는 `while True` 반복문을 끝내며,
반복문 아래의 `disconnect(connection)`으로 연결을 정리합니다.

서버는 다음 순서로 읽습니다.

1. `start_server()`로 접속받을 준비를 합니다.
2. `wait_for_clients()`로 두 사람이 들어올 때까지 기다립니다.
3. `close_server_waiting()`으로 새 접속 대기를 끝냅니다. 이미 연결된 두 사람은 대화할 수 있습니다.
4. `relay_messages()`로 두 사람의 메시지를 서로에게 전달합니다.
5. 한 사람이 나가면 연결을 정리하고 끝납니다.

`room`은 두 사람의 연결과 받은 메시지를 묶은 값입니다.
처음에는 내부 구조를 몰라도 함수에 전달해서 사용할 수 있습니다.

`wait_for_clients()`가 실행되는 동안 다음 줄은 실행되지 않습니다.
두 사람이 연결되어 함수가 값을 돌려주면 `close_server_waiting()`이 실행됩니다.
이때 새 접속을 받는 소켓만 닫으므로 이미 접속한 두 사람은 계속 연결되어 있습니다.
이후 `relay_messages()` 안의 반복문이 대화를 전달하고,
한 사람이 나가서 이 함수가 끝나면 마지막 종료 안내가 출력됩니다.

## module.py에 맡긴 부분

- `socket`: 서버와 클라이언트 사이에 데이터를 보냅니다.
- `threading`: 입력을 기다리는 중에도 상대 메시지를 받습니다.
- `queue`: 여러 곳에서 들어오는 내용을 순서대로 처리합니다.
- UTF-8과 줄바꿈: 한글을 처리하고 메시지 한 개의 끝을 구분합니다.
- `try` / `except`: 접속 실패나 연결 끊김을 안내하고 연결을 정리합니다.

화면은 터미널의 기본 입력과 출력만 사용합니다.
입력 도중 메시지를 받으면 화면의 글자가 섞여 보일 수 있습니다.

주소 `127.0.0.1`은 지금 사용하는 컴퓨터를 뜻하므로 같은 컴퓨터에서만 접속됩니다.
두 `main.py`의 포트 번호는 같아야 합니다. 기본값은 `12345`입니다.
서버를 열 수 없다면 같은 포트를 쓰는 프로그램이 있는지 확인하거나,
두 파일의 포트 번호를 함께 바꿉니다.

## 동작 검사

실행 중인 예제 서버와 클라이언트를 종료한 뒤 프로젝트 폴더에서 실행합니다.
기본 포트 `12345`를 사용해 실제 서버와 클라이언트를 띄워 검사합니다.

```sh
python3 -m unittest discover -s tests -v
```

한글과 이모지, 긴 메시지, 양방향 전송, 대기 중 종료, 서버 중지,
서버가 없거나 포트가 이미 사용 중인 경우를 확인합니다.
